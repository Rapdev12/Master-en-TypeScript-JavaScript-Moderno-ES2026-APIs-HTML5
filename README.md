## 🚀 About the Repository

This repository contains my hands-on projects, exercises, and code implementations as I progress through the **Master in TypeScript, Modern JavaScript (ES2026), and HTML5 APIs** course. 

The goal of this repository is to demonstrate strong proficiency in modern frontend development, robust typing with TypeScript, asynchronous programming, and the latest web platform features.

---

## 🛠️ What You Will Find Here

* **Advanced JavaScript (ES2026 & Modern Features):** Closures, prototypes, asynchronous JavaScript (Promises, async/await), modules, and modern syntax enhancements.
* **TypeScript Mastery:** Static typing, interfaces, generics, advanced types, decorators, and strict configuration for scalable applications.
* **HTML5 APIs:** Practical implementations of native browser capabilities (Fetch API, Geolocation, Web Storage, Canvas, Drag and Drop, and more).
* **Clean Code & Best Practices:** Modular code structure, error handling, and maintainable architecture.
